Lua on Claviron

A Lua 5.5 application loaded once per worker and woken by requests — routed by claviron.router, served under /lua.

GET /lua

The request as the application sees it. served counts this worker's requests: state stays between them.


  


  

    
GET /lua/hello/{name}

    
A path parameter.

    

    

  


  

    
GET /lua/count

    
A reply whose body is a function: each call is one piece, sent as it is made.

    
    

  


  

    
GET /lua/db/{n}

    
SQL with claviron.db, on the server's own PostgreSQL pool: a series of n rows, each value typed as Lua holds it.

    

    

  


  

    
POST /lua/echo

    
The request body, read with request:body() and decoded by claviron.json.

    
    
    

  


  

    
POST /lua/words

    
Words and numbers in a text, found with claviron.regex — Rust's regex, which never backtracks.

    
    
    

  

  

    
wss:// /lua/socket

    
A chat among the sockets of one worker: the Lua state is shared, so a table holds who is connected. /who asks how many; open a second tab to talk to it.
